Websites

対象となるユーザーやサイトの目的を整理し、情報の見つけやすさと使いやすさを意識して制作したWebサイトを掲載しています。

Featured Website

シニア向けスマホ教室「若葉」

公開中

Overview

概要

シニア向けスマホ教室を想定した架空サイトです。1ページ構成から、講座・FAQ・お問い合わせ・コラムなどを含む複数ページ構成へ改善しました。

Audience

想定ユーザー

スマートフォンの基本操作に不安を感じるシニアと、教室選びを支える家族を想定しています。

Purpose

制作目的

必要な情報を迷わず見つけ、無料体験・電話・LINE・フォームから安心して問い合わせられるサイトを目指しました。

Information architecture

情報設計

トップページでは教室の全体像を伝え、講座・料金、講師、アクセス、FAQ、問い合わせ、プライバシーポリシー、コラムを個別ページに分けました。

Design

デザイン方針

落ち着いたグリーンと丸みのあるカードを基調に、文字サイズ・行間・ボタンの大きさを確保し、読みやすさと親しみやすさを整えました。

Features

主な機能

  • 文字サイズ変更
  • FAQアコーディオン
  • LINE相談モーダル
  • 画像スライダー
  • 問い合わせフォーム（デモ）
  • 初心者向け記事コンテンツ

Accessibility

アクセシビリティ上の工夫

  • キーボード操作とフォーカス表示
  • FAQの開閉状態を支援技術へ通知
  • モーダル内へのフォーカス移動・復帰
  • Escキーによるモーダル終了
  • 代替テキストとフォームラベル

Responsive

レスポンシブ対応

PC・タブレット・スマートフォンに対応し、画面幅に応じてナビゲーションやカード、問い合わせ導線が読みやすく並ぶよう調整しています。

SEO & publishing

SEO・公開対応

ページ別のtitle・description、見出し構造、内部リンク、OGP、Twitter Card、FAQ・記事・教室情報のJSON-LDを実装し、GitHub Pagesで公開しています。

今後の改善：canonical・OGP URL・OGP画像の絶対URL設定など、公開URLに合わせた仕上げを予定しています。

Technology

使用技術

  • HTML
  • CSS
  • Tailwind CSS
  • JavaScript
  • JSON-LD
  • GitHub Pages

概要・想定ユーザー

北欧・淡色系の食器やインテリアを好み、商品を落ち着いて比較したいユーザーを想定した架空のECサイトです。
