CATEGORY / WEB-02

WEBSITES

伝えたいことを、
迷わず届く形にする。

対象となるユーザーやサイトの目的を整理し、情報の見つけやすさと使いやすさを意識して制作したWebサイトを掲載しています。

TAKEOUT / WEB EXPERIENCE

FEATURED / TODAY'S SPECIAL

WEB-01

シニア向けスマホ教室
「若葉」

WEBSITE / SENIOR SUPPORT

公開中

シニア向けスマホ教室を想定し、安心して情報を探し、問い合わせへ進めるよう設計したWebサイトです。

BACKGROUND / 01

制作背景

シニア向けスマホ教室を想定した架空サイトです。1ページ構成から、講座・FAQ・お問い合わせ・コラムなどを含む複数ページ構成へ改善しました。

AUDIENCE / 02

想定ユーザー

スマートフォンの基本操作に不安を感じるシニアと、教室選びを支える家族を想定しています。

CHALLENGE / 03

解決した課題

必要な情報を迷わず見つけ、無料体験・電話・LINE・フォームから安心して問い合わせられるサイトを目指しました。

PROCESS / DESIGN RECIPE

DESIGN
RECIPE

このサイトをどう設計したか。情報と体験を組み立てた6つの工程です。

01

INFORMATION ARCHITECTURE

情報設計

トップページでは教室の全体像を伝え、講座・料金、講師、アクセス、FAQ、問い合わせ、プライバシーポリシー、コラムを個別ページに分けました。

02

DESIGN

デザイン方針

落ち着いたグリーンと丸みのあるカードを基調に、文字サイズ・行間・ボタンの大きさを確保し、読みやすさと親しみやすさを整えました。

03

FEATURES

主な機能

  • 文字サイズ変更
  • FAQアコーディオン
  • LINE相談モーダル
  • 画像スライダー
  • 問い合わせフォーム（デモ）
  • 初心者向け記事コンテンツ
04

ACCESSIBILITY

アクセシビリティ上の工夫

  • キーボード操作とフォーカス表示
  • FAQの開閉状態を支援技術へ通知
  • モーダル内へのフォーカス移動・復帰
  • Escキーによるモーダル終了
  • 代替テキストとフォームラベル
05

RESPONSIVE

レスポンシブ対応

PC・タブレット・スマートフォンに対応し、画面幅に応じてナビゲーションやカード、問い合わせ導線が読みやすく並ぶよう調整しています。

06

SEO / PUBLISHING

SEO・公開対応

ページ別のtitle・description、見出し構造、内部リンク、OGP、Twitter Card、FAQ・記事・教室情報のJSON-LDを実装し、GitHub Pagesで公開しています。

今後の改善：canonical・OGP URL・OGP画像の絶対URL設定など、公開URLに合わせた仕上げを予定しています。

TECHNOLOGY / INGREDIENTS

使用技術

  • HTML
  • CSS
  • Tailwind CSS
  • JavaScript
  • JSON-LD
  • GitHub Pages
