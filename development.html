Case 01 / Web Application

Career Track

継続開発中

Overview

概要

企業情報・応募状況・面接準備を一元管理し、今確認すべき企業と次に行うことを整理するWebアプリです。

Background

制作背景

就職活動で企業情報、応募状況、提出期限、面接予定が複数の場所へ分散し、管理が煩雑になった経験から制作を始めました。

Problem

解決したい課題

次に行うことが分かりづらい、予定を見落としやすい、企業を比較しにくいといった管理上の負担を減らすことを目指しています。

Functions

主な機能

  • 企業情報管理
  • 応募状況管理
  • 面接予定・面接対策
  • 企業評価
  • LocalStorageによるローカル保存
  • JSONバックアップ・復元

Technology

技術

  • React
  • TypeScript
  • Vite
  • React Router
  • Tailwind CSS
  • LocalStorage
  • Git
  • GitHub

Status

現在

実際の就職活動で利用しながら、必要になった機能を追加し、操作や情報の見つけやすさを継続的に改善しています。

Case 02 / Management Tool

Design Works Admin

Local Tool
JSONEDITEXPORT

design-works.json

Background

作品管理を、手編集から画面操作へ

作品数が増え、JSONを直接編集する運用が煩雑になったため、作品追加、タグ管理、代表作品設定、公開設定、JSON出力をブラウザ上で行える管理画面を制作しました。

Overview

概要

Designページの作品データを読み込み、編集結果をJSONファイルとして書き出すローカル作業用の管理画面です。

Data

JSON管理

既存スキーマを維持し、読み込み時と書き出し前にデータ形式や必須項目を検証します。

Publishing

公開設定

Designページへの掲載と、最大3点の代表作品設定を分けて管理します。

作品追加タグ管理並べ替え代表作品管理公開設定JSON書き出し簡易プレビュー

Technology

技術

  • HTML
  • CSS
  • JavaScript
  • JSON
  • File API
  • Drag and Drop API

Operation

運用方法

静的サイトのためサーバーへ直接保存せず、JSONとfile://用フォールバックをダウンロードしてリポジトリ内のファイルと置き換えます。
