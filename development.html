Case 01 / Web Application

Career Track

継続開発中

Background

制作背景

就職活動で企業情報、応募状況、提出期限、面接予定が複数の場所へ分散し、管理が煩雑になった経験から制作を始めました。

Problem

誰のどんな課題を解決するか

就職活動中に、次に行うことが分かりづらい、予定を見落としやすい、企業を比較しにくいといった管理上の負担を減らします。

Solution

解決方法

企業情報・応募状況・面接準備を一元管理し、今確認すべき企業と次に行うことを整理できる形にしました。

Design & implementation

設計・実装上の工夫

情報を企業単位で整理し、応募状況、面接予定、企業評価を確認できる構成にしています。LocalStorageによる保存とJSONバックアップ・復元にも対応しています。

  • 企業情報管理
  • 応募状況管理
  • 面接予定・面接対策
  • 企業評価

Technology

技術

  • React
  • TypeScript
  • Vite
  • React Router
  • Tailwind CSS
  • LocalStorage
  • Git
  • GitHub

Continuous improvement

継続改善

実際の就職活動で利用しながら、必要になった機能を追加し、操作や情報の見つけやすさを継続的に改善しています。

Case 02 / Management & Analytics

Writing管理・分析システム

Local Tool

note記事の掲載・更新、アクセス状況取得、PV・スキ・コメント・スキ率の管理、時系列データ蓄積までを効率化するために制作した自分用の管理・分析システムです。

Background

記事が増えても更新しやすくする

タイトル、公開日、画像、紹介文、代表記事、掲載順、アクセス状況を手動で管理する負担が増えたことから制作しました。

Problem

最新値だけでは推移が残らない

PV・スキ・コメントを上書きするだけでは、公開後の伸び方や過去の変化を後から確認できませんでした。

Solution

管理・分析・履歴を一つにする

記事情報取得、JSON出力、アクセス状況の照合と更新、スキ率計算、時系列snapshot保存までをまとめました。

Design & implementation

一つの運用フローとして設計

記事管理 → note情報取得 → アクセス状況取得 → 指標計算 → 時系列データ蓄積

Cookieやパスワード、内部APIを使わず、表示済みDOMから必要な情報だけを取得する半自動方式です。

Technology

使用技術

  • HTML
  • CSS
  • Vanilla JavaScript
  • Node.js
  • JSON
  • Bookmarklet
  • Git
  • GitHub

Feature

記事管理だけで終わらない

noteアクセス状況、PV・スキ・コメント、スキ率、時系列履歴まで扱う「管理＋分析＋履歴蓄積」の仕組みです。
