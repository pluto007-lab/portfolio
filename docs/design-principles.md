# Portfolio v2 Design Principles

## 1. 目的

Portfolio v2では、ページや要素を「なんとなく」で決めず、対象ユーザーと目的に基づいて設計する。

## 2. 制作原則

各要素について、次の理由を説明できる状態を目指す。

- なぜこのフォントなのか
- なぜこの色なのか
- なぜこの余白なのか
- なぜこの順番なのか
- なぜここにこの要素があるのか
- 誰に向けたページなのか

## 3. ページ制作前の確認項目

- 対象ユーザー
- ページの目的
- 最初に見せたい情報
- 世界観
- フォント選定理由
- 配色理由
- 余白の役割
- 情報の順序
- 改行の自然さ
- そのページを一言で説明できるか

## 4. ページ固有の表現と共通要素

ページごとに世界観と見た目を変える。

- Web Apps：作業机・日常の課題解決
- Websites：情報設計・読みやすさ
- Design：ギャラリー
- Development：研究室・設計室
- Planning & Direction：企画会議室
- Writing：書斎
- Lab：実験室・研究ログ

次の要素は全ページで共通化する。

- ヘッダー
- フッター
- 基本配色
- フォント体系
- ボタン
- フォーカス表示
- レスポンシブ基準

## 5. 共通コピーの表示

> Building, learning, and experimenting.
>
> <small>つくり、学び、実験する。</small>

- 英語を主表示とする
- 日本語は少し小さく、薄い色で添える
