How to use

管理画面の使い方

この画面での編集は、ファイルを書き出してリポジトリへ置き換えるまでDesignページには反映されません。

  1. 作品を編集する一覧から作品を選び、内容や表示状態、並び順を調整します。
  2. 2つのファイルを書き出すdesign-works.jsonとdesign-works-fallback.jsをダウンロードします。
  3. portfolio/data内のファイルを置き換えるダウンロードした同名ファイルで既存ファイルを置き換えます。
  4. Git commit差分を確認し、変更をコミットします。
  5. Git push公開ブランチへpushするとDesignページへ反映されます。
